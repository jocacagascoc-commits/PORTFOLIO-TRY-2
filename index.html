Project Case Study

How I built and solved problems in JOACHIM ESPORTS

The Objective

The goal was to create a clean, responsive landing page for an esports brand that works on mobile and desktop. The user requirement was fast loading, clear navigation, and easy access to links like live demo and GitHub.

The Architecture

I chose pure HTML5 and CSS3 for simplicity and fast performance. Used CSS Grid and Flexbox for layout instead of heavy frameworks. This keeps the site lightweight and easy to maintain while learning core fundamentals.

Technical Challenge

I hit an issue with images overflowing on mobile and the layout breaking on small screens. Also had problems with the navigation not being responsive.

The Resolution

I fixed it by using object-fit: cover for images and adding media queries for breakpoints at 768px and 1024px. I also used Flexbox for the navbar to make it stack vertically on mobile. Tested on Chrome DevTools device mode.
